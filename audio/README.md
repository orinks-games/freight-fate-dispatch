# Sound sources

Everything under `assets/sounds` is generated by the two scripts here and
compiled into the game by key: `assets/sounds/ui/cursor.wav` is the sound
`ui/cursor`, and so on. A file of the same key in a `sounds` folder beside
the game replaces the built-in one.

## Tools

- Python 3 with `numpy`, `scipy`, `soundfile`, `pyfluidsynth` and
  `pedalboard` (`pip install` them).
- libfluidsynth (Ubuntu: `fluidsynth libfluidsynth-dev`).
- The MuseScore General SoundFont (Ubuntu: `musescore-general-soundfont`,
  installed at `/usr/share/sounds/sf3/MuseScore_General_Full.sf3`; MIT
  licensed). `FF_DISPATCH_SOUNDFONT` points at another path.
- `ffmpeg` with libvorbis.

Run both scripts from the repository root.

## Music: `soundtrack.py`

Three pieces, each written in the script as notes and rendered as six
stems (one bed and five voices) into `assets/sounds/music/<piece>/`:

| Piece | Tempo and key | Loop | Heard |
|---|---|---|---|
| First Light | 98, G major, light swing | 16 bars, 39.18 s | the desk until noon, and the start screen |
| Rolling | 100, A major, train beat | 16 bars, 38.40 s | the afternoon |
| Night Desk | 75, E minor, half time | 16 bars, 51.20 s | from 5 PM |

The engine plays every stem of a piece together as a sample-locked loop
and arranges them afresh each performance (`hearken::Stems`): which
voices open, the order they join, where some drop out, how long it runs.
`src/audio.rs` lists the stems and picks the piece by the desk clock.

Each stem loops without a seam because it is rendered three times
through as one continuous take, mastered as one, and the second pass is
kept: its first sample already carries the ringing tail of its own end.
The script measures the start of the third pass against the second and
refuses a stem that differs. Two things make this hold:

- FluidSynth is driven a 64-frame block at a time through its C API (not
  the command line player, which times events in whole milliseconds and
  drifts against the blocks), and every pass uses the same humanised
  timing and velocities.
- A loop is a whole number of 64-frame blocks, which limits the tempos:
  with 64 beats, `2 646 000 / bpm` must be an integer (75, 80, 84, 90,
  98, 100, 105, 112, 120 all work; 96 does not). The script asserts it.

Every stem of a piece must stay the same length; `src/audio.rs` carries
the lengths. `--wav` also writes each stem and the full mix to a
`ff-dispatch-music` folder under the system temp folder, to listen to.

## Effects: `effects.py`

Every interface sound and effect, built from parts in the script:
resonant bodies struck by short bursts (clicks, clunks, bells), shaped
noise (air, paper, wind, the radio), pulse trains through resonators
(diesel engines), and short stings on sampled instruments. Each sound is
given a room, levelled by its loudest 50 ms, and written as WAV, or as
Vorbis past 1.3 seconds.

To add a sound: write its function, add a `Sound` row to `SOUNDS` with
its key and level, run `python3 audio/effects.py <key>`, and add the key
to the `cues!` table in `src/audio.rs`.

Keys and where the game plays them:

| Key | Played when |
|---|---|
| `ui/cursor`, `ui/activate`, `ui/back`, `ui/error`, `ui/success`, `ui/notify`, `ui/type` | menus, the typed folder field, and the engine's own screens |
| `sfx/phone_ring`, `sfx/phone_pickup`, `sfx/phone_hangup` | the phone rings, is answered, and the call is resolved |
| `sfx/hours`, `sfx/breakdown`, `sfx/dock`, `sfx/weather` | after the pickup, for the incident on the line |
| `sfx/radio` | a load is dispatched |
| `sfx/truck_idle` | checking on a truck |
| `sfx/clock` | waiting for what's next |
| `sfx/delivered`, `sfx/late` | a load delivered on time, or late |
| `sfx/goal` | the daily goal is met |
| `sfx/hire` | a driver is hired |
| `sfx/door` | a driver quits overnight |
| `sfx/day_start`, `sfx/day_close` | the desk opens and closes |
| `sfx/air_brakes`, `sfx/truck_depart`, `sfx/horn`, `sfx/paper`, `sfx/stamp`, `sfx/cash`, `sfx/bill`, `sfx/alert`, `sfx/inspection`, `sfx/citation`, `sfx/out_of_service`, `sfx/week_close`, `sfx/lose` | not yet: made for tenders, settlements, inspections, citations, out-of-service orders, the weekly scorecard and the end of a career |
